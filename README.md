# Sadia Afrin Moon — Personal Portfolio

Responsive personal portfolio built with HTML, CSS and JavaScript.

## Setup
1. Place a JPG profile photograph named `profile.jpg` in this folder.
2. Edit placeholder university, skills, academic years, experience, and actual GitHub username in `index.html` after confirmation.
3. Open `index.html` in a browser.
4. Upload the files to a new public GitHub repository, then enable GitHub Pages from `main` / `(root)`.
